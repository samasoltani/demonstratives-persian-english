# Demonstratives in Persian and English (این/آن vs this/that)

A corpus study of the functions of demonstratives (spatial, temporal, discourse, recognitional, emotional, non-deictic) in child-parent speech, using CHILDES.

## Structure
- `data/raw/persian/` – CHAT (.cha) files of Leila and Minoo
- `data/raw/english/` – English comparison corpus (to be chosen)
- `data/interim/` – extraction outputs (CSV)
- `data/annotated/` – annotated data
- `src/` – scripts, prefixed by run order (01-, 02-, ...)
- `outputs/` – tables, figures, model results
- `docs/` – annotation guide and notes

## Run order
Scripts in `src/` are run in the order of their numeric prefix.
